## About DEMO Graph Tool

DEMO Graph Tool is a single-file HTML demo for creating interactive graphs in the browser. It is designed to help users explore inferred links between startups, products, and people through a visual, node-based experience.

The tool combines AI-driven inference with Google search results to suggest connections and build a browsable graph. Because it runs entirely in the browser, it is a lightweight way to prototype relationship mapping without setting up a server-side application.
